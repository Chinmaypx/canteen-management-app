# Canteen Management App

A web-based canteen management application designed to simplify food ordering, menu management, payments, and order tracking.

## Features

- User login functionality
- Online food ordering
- Menu management
- Admin functionality
- Order management and order history
- Payment recording
- User feedback and ratings

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

## Project Structure

- `index.html` – Main entry page
- `home.html` – User home page
- `menu.html` – Displays the food menu
- `orders.html` – Order-related functionality
- `payment.html` – Payment functionality
- `Admin.html` – Admin interface
- `server.js` – Backend server and API endpoints
